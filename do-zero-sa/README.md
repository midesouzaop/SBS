# Do Zero a S.A. — protótipo de plataforma

Primeira versão visual e responsiva do catálogo de aulas e do estúdio de criação.

## Incluído nesta etapa
- Catálogo visual em estilo streaming premium.
- Paleta grafite, azul profundo e violeta discreto.
- Cards de cursos e progresso ilustrativo.
- Área conceitual do estúdio para aulas originais e vídeos animados.
- Seleção local de arquivos para demonstrar a fila de upload.
- Modal para definir um projeto de produção.

## Limites desta prévia
Esta é uma interface estática (HTML/CSS/JavaScript). Os arquivos selecionados não são enviados nem armazenados num servidor. Autenticação, banco de dados, upload persistente, transcrição, processamento FFmpeg/Whisper, geração de animações e publicação de aulas precisam ser implementados e hospedados em etapas seguintes.

## Visualização
Abra `index.html` em um navegador ou publique a pasta `do-zero-sa` num serviço de hospedagem estática.
